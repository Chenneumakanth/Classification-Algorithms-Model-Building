# Classification Algorithms – Model Building

## 📌 Overview

This project focuses on building and comparing **machine learning classification models using Python** to predict the success of crowdfunding campaigns.

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Topics Covered

### 1. Data Exploration & Preprocessing
- Loading and exploring the crowdfunding dataset
- Checking missing values
- Removing unnecessary columns
- Encoding categorical variables
- Splitting data into training and testing sets

### 2. Classification Algorithms
- Decision Tree Classifier
- Random Forest Classifier
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Support Vector Machine (SVM)

### 3. Model Evaluation
- Accuracy score
- Precision, Recall and F1-score
- Stratified cross-validation
- Hyperparameter tuning
- Model performance comparison

## 📈 Key Results

- Best-performing model: **Decision Tree Classifier**
- Test accuracy: **99.46%**
- F1-score: **0.9945**

## 🎯 Objective

The objective of this assignment is to understand and apply **classification algorithms** and evaluate their performance in predicting crowdfunding campaign success.
